# Capstone Mobile
“Chantek” is a mobile application that focuses on providing user with comprehensive toolkit to help them manage their mental health with functionalities such as stress monitor, community forum to feel a sense of belonging, online therapist booking, finding activities according to stress level and lifestyle, and giving motivational quotes.

## Installation
```bash
$ flutter pub get
```

## Running the app
```bash
$ flutter run
```

## Building the app
```bash
# App
$ flutter build appbundle

# Apk
$ flutter build apk

# Build assets
$ flutter build bundle
```
